   - `Mesh` dataclass: nodes/elements dicts (insertion order = deterministic),
     ordered boundary node `groups` (bottom/right/top/left, xmin..zmax) AND
     `sides` = (ele_tag, local_edge) tuples for applying edge tractions.
   - **Quality gate** `check_quality`: quads — detJ > 0 at 2×2 Gauss points AND
     corners, side aspect, corner angles, warp (3D quads); hex — detJ at 2×2×2 +
     corners, edge aspect. Raises `MeshQualityError` carrying element tag, metric,
     value, limit. Limits configurable per call (defaults: aspect 10, angles
     20–160°, warp 0.05).
   - **`stitch_edge`**: ties a fine edge to a coarse edge — coincident nodes →
     equal-DOF; hanging nodes → linear-interpolation MP on the coarse segment's
     end nodes. Documented approximation (keep away from regions of interest).

2. **MP constraints generalized to multi-retained terms** (a hanging node has TWO
   retained nodes): `MP_Constraint.terms` property (one-term view),
   `MP_ConstraintMulti` + `hanging_node()` in `constraints/mp.py`;
   `AnalysisModel.build` + `Domain.add_mp_constraint` resolve through `.terms`.
   Single-retained path bit-identical (all step-1 MP tests untouched, green).

3. **`isoparam.py`**: `H8_CORNERS` + `shape_h8` trilinear shapes (hex Jacobian
   gate now; Step 6 solids consume later).

4. **`api.py` hooks**: `Model.mesh_line/mesh_rect/mesh_transfinite` — gate runs
   BEFORE any node/element is emitted (a failing mesh adds nothing to the domain);

## What was built

1. **`src/fea/elements/frame3d.py` (new):** `Frame3D` — 2-node, 6-DOF/node
   linear elastic 3D frame. Local 12×12 = axial EA/L + St-Venant torsion
   GJ/L + Euler-Bernoulli EIz (x-y plane, the existing `_bernoulli_4x4`
   unchanged) + EIy (x-z plane, theta rows/cols sign-flipped:
   `k_xz = S·B(EIy)·S`, S = diag(1,−1,1,−1), because right-handed
   θy = −dw/dx). Orientation = OpenSees geomTransf convention: `vecxz`
   (REQUIRED — no silent default) in the local x-z plane; ey = vecxz × ex,
   ez = ex × ey. Releases (`release_i/j` = 3D pin: BOTH My and Mz condensed
   out; torsion stays continuous) and offsets (rigid link
   u_end = u + θ×o, translation-rotation block = −skew(o)) generalize the
   validated 2D implementations. The 2D `Frame` is untouched (regression
   baseline). Constructor validates section has positive Iy/J/G.

2. **`src/fea/loads/pattern.py`:** `FrameUniformLoad3D` (wx/wy/wz) +
   `FramePointLoad3D` (Px/Py/Pz at distance_from_i), GLOBAL components,
   projected by the element via its 3×3 rotation and turned into
   consistent nodal loads with the same Hermite integrals as 2D (x-z
   plane terms get the θy sign flip).

3. **`src/fea/api.py`:** `element("Frame3D", tag, i, j, section=, vecxz=,
   release_i/j=, offset_i/j=)`; `ele_load` gained `wz`/`Pz` and dispatches
   Frame3D before Frame; passing wz/Pz to a 2D Frame raises.

4. **`Reference/macneal_harder_models.json`:** 3D cases un-deferred
   (`runnable_3d: true` + closed forms); added exact St-Venant
   J = 4.573634e-5 for the 0.2×0.1 rectangle (series formula documented).
