### What was built

- `src/fea/elements/isoparam.py` — shared isoparametric kernels, built once
  for the whole continuum family (Quad4 now; MITC4 membrane Step 5; Hex8/Tet4
  Step 6): Q4 bilinear shape functions + parametric derivatives, Gauss-Legendre
  1D (1/2/3-pt) / 2D / 3D tensor rules, Jacobian helper (signed detJ, physical
  derivatives), 2D Voigt B-matrix builder.
- `src/fea/materials/nd.py` — `NDMaterial` ABC (strain VECTOR in -> stress +
  tangent matrix out, committable state, `copy()` so elements hold one instance
  per Gauss point — ready for Phase 5 path-dependent materials) and
  `ElasticIsotropic` with plane_stress / plane_strain / solid3d D-matrices.
- `src/fea/elements/quad4.py` — 4-node bilinear quad, 2 DOF/node, full 2x2
  integration, uniform thickness t.
  - Raises at `set_domain` on non-positive Jacobian (inverted / clockwise
    node numbering) — same rule the Step 3 mesher quality gate will enforce.
  - Element loads follow the Frame `_q0` pattern (resisting = internal − q0,
    tangent stays exact): `QuadBodyLoad` (bx/by per unit volume) and
    `QuadEdgeLoad` (constant traction per unit area on a straight edge:
    global tx/ty + scalar `pressure`; **positive pressure pushes INWARD** —
    LE1's outward 10 MPa tension is `pressure=-10`).
  - Stress recovery: Gauss-point stresses + bilinear-fit extrapolation to
    corner nodes (`stress_gp` / `stress_nodes` responses).
- `src/fea/api.py` — `Model.nd_material("ElasticIsotropic", tag, E=, nu=,
  formulation=)`, `Model.element("Quad4", tag, n1..n4, mat=, t=)`,
  `ele_load(..., bx=, by=)` or `ele_load(..., edge=, tx=, ty=, pressure=)`.
- `Reference/nafems_le1.json` — NAFEMS LE1 geometry/material/BC/loading and
  the 92.7 MPa target, with provenance notes (public secondary sources;
  engineer may drop the NAFEMS PDF into `Reference/NAFEMS/` later).
