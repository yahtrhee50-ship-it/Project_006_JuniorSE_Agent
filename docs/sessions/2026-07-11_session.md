## Calibrated stepping convention (machine-exact, single axle + HS20 train)

- Step k = time `t = (k-1)·LoadDisc`; steps = `LoadDur/LoadDisc + 1`.
- Vehicle **absent for `t < StartTime`**, applied AT its start station from
  `t = StartTime` (probed: start_time=4 → t=0..3 zero load, t=4 lead axle
  exactly at the start station).
- Lead axle at `Station_written + Speed·(t−StartTime) − 1 ft` — the vehicle's
  variable "Leading Load" segment collapses to a **1 ft default** in
  multi-step mode (front of vehicle = station). kip_ft calibration.
- Trailing axles follow at their spacings; off-span axles carry nothing.

## Gotchas learned this session

1. `.$2k` backup lacks ProgramName/Version/CurrUnits → text reopen aborts as
   "Version 0"; ALWAYS repair before `OpenFile`.
2. Vehicle-live pattern data invisible to ALL DatabaseTables reads — grep the
   freshly saved `.$2k` to verify storage.
3. Importing "Load Pattern Definitions" interactively REPLACES the whole
   pattern table (older patterns deleted) and rejects DesignType="Vehicle
   Live" (defaults to Dead + warning) — never import that table to add one.
4. Fresh-instance first-apply flake (see builder note above).
5. SAP2000 launched by a script DIES when that script exits (child-process
   tie) — serial experiment scripts each relaunch; only the uvicorn server
   keeps one alive across calls.
6. Modal dialogs from COM (`#32770`, title "SAP2000") hang calls silently;
   experiments 7-9 run a watchdog thread that logs + OK-clicks them.
7. PowerShell: `git commit -m @'...'@` with embedded double quotes splits the
   argument at the quote — keep messages quote-free.
