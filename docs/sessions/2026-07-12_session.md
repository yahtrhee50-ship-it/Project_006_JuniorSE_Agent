# Session 2026-07-12 — Full live test of Project_005 SAP2000 web API

## Goal
Test Project_005 to make sure all of the SAP2000 API functions work as intended
via the web app (REST/HTTP layer), providing original test input.

## What was done
- New script: `scripts/test_p005_api_web.py` — drives EVERY P005 SAP2000
  endpoint over plain HTTP (urllib, no MCP layer), with original test input:
  - **Model 1 (kip_ft floor deck):** 36×18 ft, 9-in slab (fc 4 ksi, 3-ft mesh,
    72 shells), 4 W21X62 girders at y=0/6/12/18, frame_group "EDGE" W16X31
    along Y at x=0/36 (first live test of the frame_groups build path),
    8 pinned piles at girder ends, 4 W12X65 columns (11 ft, fixed) added at
    midspan via op/add_columns. SDL 25 psf, LL 80 psf.
  - **Model 2 (moving load):** 60-ft single W24X94 girder, custom general
    vehicle TRK2438 (24 + 38 kip axles @ 15 ft, no lane load), MOVE1 envelope,
    then op/add_multistep_moving_load (10 ft/s, 9 s, 1-s steps → 10 steps).
- Coverage: /health, GET /op (11/11 ops), /status (before/after connect,
  after close), POST /api/preview, /connect, /build-from-json (save_path and
  run_analysis query params), all 11 /op/* operations, /close, plus negative
  tests (invalid model → 422, unknown op → 404, bad multistep value → clean
  500 with a helpful message).

## Result — ALL 63 CHECKS PASS (2026-07-12, live run)
- Case sums exact vs hand statics: LL 51.840, SDL 16.200, DEAD 85.845 kips
  (ratio 1.00000 incl. steel self-weight at 0.490 kcf).
- Joint reactions: 12 restrained joints, equilibrium exact, all four
  double-symmetry groups equal to 1e-6.
- Cross-op consistency: column axial P == its base reaction F3 (5.309672 kips).
- Combos: LC1 = 1.4D and LC2 = 1.2D+1.6L factored sums exact.
- modal_periods returned real modes (MODAL case runs by default; T1 = 0.0446 s).
- MOVE1 envelope vs exact influence lines: support maxima 56.000/56.000 kips
  exact (SAP runs the vehicle both directions), midspan M3 749.942 vs 750
  kip-ft (−0.008%, lane discretization).
- MSTEP1 per-step reactions and midspan M3 == exact axle statics to machine
  precision (worst |dR| = |dM| = 0.000000) across all 10 steps; envelope and
  last_step multistep variants consistent; base_reactions populated for the
  multistep static case (unlike moving cases).
- Saved deliverables: P005 `outputs/api_test_deck.sdb`,
  `outputs/api_test_moving.sdb`. SAP2000 closed cleanly via API at the end.
