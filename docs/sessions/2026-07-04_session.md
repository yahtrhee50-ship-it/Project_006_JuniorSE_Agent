## 2. NEW GOAL (user, session-scoped): add SAP2000 features, modularized for later tool conversion

**Commit (P005):** `9f7247a` (pushed to master).

### Pattern established — `services/sap2000/operations/`
- Every capability = standalone `func(conn, **json_params) -> json_dict`, registered in
  `OPERATIONS` dict in `operations/__init__.py`.
- One generic route dispatches by name: `POST /api/sap2000/op/{name}` (body = kwargs JSON);
  `GET /api/sap2000/op` lists operations + first docstring lines.
- Adding a new operation = 1 function + 1 registry entry. Each function converts 1:1 into
  an MCP tool later (that's the design intent — junior-se server can wrap them).

### First feature batch: analysis-results extraction (`operations/results.py`)
`list_load_cases`, `joint_reactions`, `joint_displacements`, `frame_forces`,
`base_reactions`, `modal_periods`.

**COM tuple layouts verified live** (probe scripts, session scratchpad):
- comtypes returns all ByRef params as a tuple, **ret code LAST** (`r[-1]`, 0=ok).
- `JointReact`/`JointDispl`: r[0]=n, 1=Obj, 2=Elm, 3=LoadCase, 4=StepType, 5=StepNum,
  6–11 = F1,F2,F3,M1,M2,M3 (or U1..R3), 12=ret.
- `FrameForce` (13 placeholder lists after Name+ItemType!): r[0]=n, 1=Obj, 2=ObjSta(numeric),
  3=Elm, 4=ElmSta, 5=LoadCase, 6=StepType, 7=StepNum, 8–13 = P,V2,V3,T,M2,M3, 14=ret.
- `BaseReact`: r[0]=n, 1=LoadCase, 2=StepType, 3=StepNum, 4–9 = FX..MZ, 10–12 = gx,gy,gz, 13=ret.
- `ModalPeriod`: r[0]=n, 1=LoadCase, 2=StepType, 3=StepNum(mode), 4=Period, 5=Freq,
  6=CircFreq, 7=EigenValue, 8=ret.
- `LoadCases.GetNameList` / `GroupDef.GetNameList`: (n, names, ret).
- `Analyze.GetCaseStatus`: (n, names, statuses, ret); status 4=finished, 1=not run.
- Group query: `("ALL", ItemTypeElm=2)` works (group "ALL" always exists); joint queries
  by name use ItemTypeElm=0.

case finished**. Observed: a SAP2000 instance orphaned by a killed COM client accepts all
build/save calls and returns 0 from RunAnalysis **without running anything** (model never
locks, all Results.* return ret=1/0 rows). Restarting SAP2000 fixed it.
