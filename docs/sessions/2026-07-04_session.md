### Pattern established — `services/sap2000/operations/`
- Every capability = standalone `func(conn, **json_params) -> json_dict`, registered in
  `OPERATIONS` dict in `operations/__init__.py`.

## 3. P005 `define_load_combos` operation — COMPLETE (session 2, after /clear)

**Commit (P005):** `88d5e79` (pushed to master).

- `operations/combos.py`:
  - `generate_lrfd_combos(case_map)` — PURE enumerator (no COM), unit-testable.
    Expands ASCE 7-22 "or" alternatives into variants: `0.5(Lr|S|R)` → one variant per
    mapped roof type; combo 3's `(L or 0.5W)` → one variant per mapped companion.
    Names: `LC2` if single variant, else `LC2a/LC2b/...`. Skips combos whose
    distinguishing load is unmapped (no W → LC4/5, no E → LC6/7, no roof → LC3),
    returned in `skipped` with reasons. `D` is required in case_map.
  - `define_load_combos(conn, case_map, prefix="", envelope=True, replace=True)` —
    creates linear-additive `RespCombo`s + `<prefix>LRFD-ENV` envelope combo
    (RespCombo.Add type 1) over all created combos. Validates case_map names against
    model cases AND combos (a mapped name may itself be a combo). `replace=True`
    deletes same-named combos first (idempotent). Payload carries equations, code
    refs, per-case factors, and explicit assumptions (no LL reduction; companion L
    at 1.0 — 0.5L exception not taken; W/E reversal = engineer's job, map directional
    cases or call per direction with a `prefix`).
- COM notes: `RespCombo.Add(name, type)` returns bare int ret; `SetCaseList(name,
  cNameType, caseName, sf)` with cNameType 0=case 1=combo returns tuple, ret last.
  `_check` in combos.py uses `ret_code[-1]` (results.py's uses `[0]` — fine there
  because those tuples are checked via `r[-1]` at call sites).
- **Verified live** (`scripts/test_combos_operation.py`, 25/25 PASS): pure-logic
  full-map enumeration (12 combos incl. 4 LC3 variants), D+L-only subset, missing-D
  rejection; live: combos created in SAP2000, second call idempotent, unknown case
  name rejected with model case list, and **factored reactions match statics
  exactly** — LC1: 7 kN/support (1.4·10/2), LC2: 22 kN (1.2·10+1.6·20)/2, LRFD-ENV
  max: 22 kN, on the standard 6 m SS test beam.
- REST dispatch not re-tested this session — generic `/op/{name}` mechanism was
  verified end-to-end last session; new op is just a registry entry.
